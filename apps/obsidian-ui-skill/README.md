# Obsidian UI Skill

This is the future Agent Skill developed by Obsidian UI System as a product alongside Obsidian UI Mapping and Obsidian UI System Figma. Its intended role is to help coding agents interpret the shared UI representation and, eventually, turn structured designs into Obsidian implementations.

Only the product location is reserved. No skill instructions or distribution package are implemented yet; that work requires a separate milestone. Skills installed to help an agent develop this repository belong to that agent's own configuration, such as `.agents/skills/` or `.claude/skills/`, rather than here.
