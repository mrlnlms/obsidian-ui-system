# Project documentation

Current scope: monorepo boundaries, a three-component Obsidian UI Atlas workspace view with deterministic variants, and local snapshot export. See [capture-milestone.md](capture-milestone.md) for the capture contract and limitations and [component-registry.md](component-registry.md) for extending the Atlas. Figma importer and coding-agent skill remain future work.

The [public UI inventory](public-ui-inventory.md) maps the locally installed Obsidian SDK's visual APIs and suggests small future capture batches.
