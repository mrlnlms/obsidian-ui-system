# Project documentation

Current scope: monorepo boundaries, a nineteen-component Obsidian UI Atlas workspace view with deterministic variants, local snapshot export, and semantic comparison of two exports. See [capture-milestone.md](capture-milestone.md) for the capture contract and limitations, [component-registry.md](component-registry.md) for extending the Atlas, [snapshot-diff.md](snapshot-diff.md) for the comparison CLI, [light-dark-capture.md](light-dark-capture.md) for the default-theme mode comparison, [settings-batch.md](settings-batch.md) for batch 3, and [overlays-batch.md](overlays-batch.md) for batch 4. Figma importer and coding-agent skill remain future work.

The [public UI inventory](public-ui-inventory.md) maps the locally installed Obsidian SDK's visual APIs and suggests small future capture batches.
