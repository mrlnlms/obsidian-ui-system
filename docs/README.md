# Project documentation

Current scope: a 26-family Obsidian UI Atlas, the separate Layout Lab, semantic snapshot comparison, a [single Figma Package ZIP](figma-package.md), and the validated [Button](figma-button-spike.md) and [Search](figma-search-spike.md) Figma pilots. The normal importer flow is **Export Obsidian UI Figma Package** in Obsidian, then **Choose ZIP → Generate UI Kit** in Figma Desktop. The [component reconstruction reference](figma-component-reconstruction.md) holds reusable rules for future components. The [public API phase closure](public-api-phase-complete.md) records completed evidence and deferred work. Full Design System import and the coding-agent skill remain future work.

The [Figma readiness assessment](figma-readiness.md) is historical: it evaluates snapshot schema 0.3.0 before Layout Lab evidence and before the Button/Search importer. See [capture-milestone.md](capture-milestone.md) for the capture contract, [component-registry.md](component-registry.md) for the Atlas registry, [snapshot-diff.md](snapshot-diff.md) for the comparison CLI, [light-dark-capture.md](light-dark-capture.md) for the default-theme mode comparison, and the batch notes for [Settings](settings-batch.md), [overlays](overlays-batch.md), [suggestions](suggestions-batch.md), and [contextual APIs](contextual-batch.md).

The [public UI inventory](public-ui-inventory.md) maps the locally installed Obsidian SDK's visual APIs and suggests small future capture batches.

The [Button/Search layout spike](layout-spike.md) preserves the focused historical evidence, including a long label wider than its 160px host. The current [experimental intermediate model](layout-spike-model.experimental.json) is generated by the generalized inference run and does not change the public snapshot schema.

The [layout inference experiment](layout-inference.md) uses declarative probes for Button, Search, Dropdown, Slider and Setting. The Layout Lab exports raw observations, sizing evidence and a generated intermediate model separately from the public snapshot schema.
The [Layout Probe Lab guide](layout-lab.md) explains the separate Obsidian command, probe declarations, exports and the point of resumption.

Files under `superpowers/plans/` are historical implementation plans. Use this index and the current READMEs for operating instructions.
