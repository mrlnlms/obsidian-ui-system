# Project documentation

Current scope: monorepo boundaries, a 26-family Obsidian UI Atlas workspace view with deterministic variants, local snapshot export, and semantic comparison of two exports. The [public API phase closure](public-api-phase-complete.md) records completed evidence and deferred work. The [Figma readiness assessment](figma-readiness.md) tests six representative components for editable and responsive reconstruction. See [capture-milestone.md](capture-milestone.md) for the capture contract and limitations, [component-registry.md](component-registry.md) for extending the Atlas, [snapshot-diff.md](snapshot-diff.md) for the comparison CLI, [light-dark-capture.md](light-dark-capture.md) for the default-theme mode comparison, [settings-batch.md](settings-batch.md) for batch 3, [overlays-batch.md](overlays-batch.md) for batch 4, [suggestions-batch.md](suggestions-batch.md) for batch 5, and [contextual-batch.md](contextual-batch.md) for batch 6. Figma importer and coding-agent skill remain future work.

The [public UI inventory](public-ui-inventory.md) maps the locally installed Obsidian SDK's visual APIs and suggests small future capture batches.

The [Button/Search layout spike](layout-spike.md) compares controlled host widths and three Button labels using real Atlas registry specimens, including a long label wider than its 160px host. Its [experimental intermediate model](layout-spike-model.experimental.json) records supported and unknown sizing decisions without changing the public snapshot schema.
